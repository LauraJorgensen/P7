# P7: Uniqueness and Identifiability in Mutational Signature Extraction: A Comparison of KL-NMF and Min-Vol KL-NMF

This repository contains the scripts for the P7 semester project at Aalborg University by group MS7-01. 

NMFfit.R defines the fit for KL-NMF and Min-Vol KL-NMF in addition to a function for calculating the generalised KL-divergence.
