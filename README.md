# P7: Uniqueness and Identifiability in Mutational Signature Extraction: A Comparison of KL-NMF and Min-Vol KL-NMF

This repository contains the scripts for the P7 semester project at Aalborg University by group MS7-01. The sampling algorithm for computing the set of feasible solutions is sourced from [Ragnhild](https://github.com/ragnhildlaursen/SFS). 

NMFfit.R implements the KL-NMF and Min-Vol KL-NMF algorithms in addition to a function to compute the generalized KL-divergence.
